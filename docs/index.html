JH EXPLODE

Ferramentas e monitoramento para Windows, por JH Maker.

Sobre o projeto

O JH EXPLODE reúne ferramentas para visualizar informações do computador, explorar utilitários e testar recursos de hardware. A disponibilidade de cada recurso depende do sistema e do hardware.

Downloads

Os arquivos de download serão publicados na seção Releases deste repositório.

O código-fonte está disponível para estudo e personalização. Para que as alterações apareçam no executável, compile o projeto atualizado no Windows com o .NET 8 SDK.
